# 5e (2014) profile sources

The optional `srd-5.1-2014` character profile uses the 2014 single-class tables. It does not change an existing sheet until the author explicitly applies selected calculations. The separate stat-block profile and its 2024 references are unchanged.

## Primary references

- [Official SRD 5.1 under CC BY 4.0](https://media.dndbeyond.com/compendium-images/srd/5.1/SRD_CC_v5.1.pdf): class hit dice, fixed hit-point increments, casting abilities and spell-slot tables. PDF pages: Barbarian8, Bard11, Cleric15, Druid19, Fighter24, Monk26, Paladin30, Ranger35, Rogue39, Sorcerer42, Warlock46 and Wizard52. Page numbers here are the printed SRD page numbers.
- [Official 2014 Basic Rules, Beyond 1st Level](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/step-by-step-characters#Beyond1stLevel): minimum one hit point gained per level and retroactive Constitution modifier changes. The minimum-one clarification is applied to fixed HP; it is not present as that parenthesis in the SRD5.1 PDF.
- [Official SRD version explanation](https://www.dndbeyond.com/posts/1949-you-can-now-publish-your-own-creations-using-the): SRD5.1 represents the 2014 rules, while SRD5.2 represents the revised rules. No 2024 class progression is mixed into this profile.
- [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

Only numeric rule facts are encoded. The interface, vector record paper and authoring controls are original. Spell names, notes, levels and prepared marks are entered by the author; no spell catalogue or rulebook descriptions are bundled. The nine species/race suggestions are editable text and do not change ability scores.

## Supported calculation boundaries

Single-class levels1–20, twelve core classes, fixed HP, proficiency from the existing sheet calculation, full/half-caster slots and separate Warlock Pact Magic. Ability selection uses a stable trait ID. Explicit spell DC/attack overrides, including zero, are supported. Manual maxima and played resources are retained; a destructive capacity reduction needs an explicitly selected preview field.

Multiclassing, subclasses, ASI/feats, rolled HP, known/prepared spell limits, spell effects, automatic rests and Mystic Arcanum are recorded manually. No complete level-up or combat adjudication is claimed. Existing sheets without this optional metadata retain their stored values and former paper geometry.
