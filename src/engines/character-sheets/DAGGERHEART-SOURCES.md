# Daggerheart class reference facts

The nine core class names, starting Evasion/HP, domain names and class/Hope
feature titles in daggerheart.ts were checked directly against the official
Daggerheart SRD 2.0, released 25 August 2026. © Critical Role, LLC. The data
notes and interface are original; no earlier third-party adaptation was used.
No rulebook prose, card layout, illustration or official logo is included.

PDF pages: Bard10, Druid14, Guardian19, Ranger20, Rogue22, Seraph24,
Sorcerer25, Warrior28, Wizard30. Page8 distinguishes the nine core classes
from the four expansion classes. The source version/page also travels in
generated editable reference rows. A Hope feature reference records its
3-Hope cost; no feature effect is automatically executed.

behavior. Class data is applied only through an explicit preview, retaining
authored edits and played resources. No advancement, subclass, ancestry,
