# Procedencia del motor de documentos de Writers

Este motor es una copia de código propia dentro de Writers, basada históricamente en Wordcraft, commit `6526b134befbf6933fd87a63bfea37a7828f29c4`, obtenida el 11-10-2026. No es una dependencia Git, submódulo, proceso de aquella aplicación ni canal de actualizaciones. El enlace al repositorio original en el manifiesto identifica la procedencia y no se utiliza en ejecución o compilación. Los paquetes Rust se llaman `writer-*`; la aplicación propia es `writer-document-engine`.

Se incorporaron los crates geom, doc, fonts, proof, layout, docx, docbin, formats, metafile, render, pdf y engine; las fuentes, diccionarios y patrones de separación silábica necesarios; los tests de esas piezas. No se incorporaron la UI egui, la aplicación original, el servidor MCP original, el canal de control original, las marcas, iconos ni empaquetado originales. Las fuentes externas opcionales dejaron de ser entradas de compilación: las fuentes distribuidas por Writers están en su propio árbol y las del sistema se descubren localmente.

Licencia de la fuente: MIT o Apache-2.0, a elección. Se conservan `native/LICENSE-MIT`, `native/LICENSE-APACHE`, `native/NOTICE` y `native/ATTRIBUTION.md` como avisos históricos originales. Las fuentes tienen sus respectivos textos OFL dentro de `native/assets/fonts`; el diccionario inglés y patrones conservan su atribución. Las entradas de NOTICE/ATTRIBUTION que describen elementos no incorporados no implican que esos elementos estén en Writers. Los logos y marcas ArtCraft excluidos de la licencia no se distribuyen aquí.

El fichero `source-provenance.json` recoge las rutas de origen, destinos y SHA-256 originales de cada archivo incorporado. Las modificaciones propias posteriores no reescriben esos hashes históricos.

Cambios propios: nuevos protocolo JSON lines, servicio de sesiones y ejecutable; archivo completo versionado de documentos con assets y partes originales; operaciones de bytes para el selector y las descargas; lotes con rollback real del estado de edición; identificadores de sesión con nonce de instancia; proceso Windows sin consola; comandos de guardado con ruta explícita; documentación y pruebas propias. Los identificadores internos OOXML históricos conservados sirven para interpretar el formato, no enlazan con ningún servicio.

La adaptación propia al HTML de Writers conserva los átomos de notas al pie y sus IDs, cortes de página, sangría, interlineado, estilos de párrafo y atributos de formato. Las notas son partes del documento nativo y llegan a DOCX y PDF. Se corrigieron además las omisiones originales de XML/relaciones de gráficos y OLE en JSON. El catálogo admite filtrado por consulta y conserva el recuento total de capacidades.

Las correcciones de la revisión independiente incluyen guardar archivos completos mediante temporal único y reemplazo atómico, mantener la contraseña de documentos Word cifrados durante la sesión, conservar anchuras de columnas y celdas combinadas en HTML/DOCX/archivo nativo y acompañar el ejecutable distribuido con los avisos y licencias de código y fuentes. Las pruebas de fallo antes del reemplazo confirman que el archivo anterior queda idéntico y que el temporal propio se limpia.

Se retiró el límite heredado de 500 pasos de deshacer para cumplir el criterio de Luis de no introducir topes: la sesión conserva todos los pasos y los snapshots mantienen el historial compartido completo. La prueba de 650 ediciones separadas, deshacerlas todas y rehacerlas demuestra también la conservación de los assets y las partes originales.

Limitaciones conservadas del código de origen: corrector y separación silábica ingleses; importación DOCX parcial para objetos avanzados; controles de contenido sin conservar sus propiedades; InkML de Word no preservado; diferencias de fuentes/paginación frente a Word; HTML no conserva todo el modelo documental. El archivo `.writer.json` sí conserva el modelo y sus bytes binarios completos. No se afirma paridad con Word, escritura castellana probada en toda plataforma ni fidelidad DOCX universal.
