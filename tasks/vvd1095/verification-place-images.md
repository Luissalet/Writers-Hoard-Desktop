Original colours retain channels; Map ink retains source alpha and uses the effective marker ink. Removing the image reveals the stored model/symbol/finish. There is no live Gallery assetId, global SDK icon registry, remote icon API or new storage table.

A flat anchored image in World3D is not a generated volumetric model. Send to Maps keeps its existing background/sync meaning, not a newly editable image pin.

For a situated settlement/ruin/landmark/region/feature, `WorldSpatialStyle.iconImage` is absent, `{dataUrl,mode:'colour'|'inked'}`, or null.
