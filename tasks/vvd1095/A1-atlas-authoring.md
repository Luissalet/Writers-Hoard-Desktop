## Framing difference that drives most rows

- VVD Map Beta authors a bounded flat sheet (km width/height, any size, unbounded sea start) painted by hand, with starters and later grow/crop.
- Writer's `worldgen` engine is a deterministic Earth-sized planet: stored as seed + params + an ordered edit list (`core/edits.ts`, replayed over the generated world). Its "sheets" (`sheets/*`, `RegionSheetView.tsx`) are crop windows over that planet. `kmPerWorldCell = EARTH_KM / world.width` (`region/terrain.ts`), so world size in km is not a user choice.
- Writer's second map surface is the `maps` engine (image + pins + vector regions/paths/labels + named layers + version history), with no terrain model.
- Writer's painting depth (9 relief ops, 4 brush tips, 4 falloffs, elevation/slope gates, per-stroke rules) is deeper than VVD's strings imply. Writer's gaps are in the authoring shell: starters, blank canvas, sheet resize flow, persisted looks, legend, layers in the worldgen map, label/glyph typography, time versions linked to a timeline.
