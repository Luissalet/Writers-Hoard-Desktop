## Normal use and boundary

Prepared local image → valid own graphic → retained model/culture/symbol. Choosing a graphic in the inspector explicitly removes the active image in the same style step. Adding an image retains the graphic as fallback. Remove graphic affects only that level; choose a model/symbol in the normal inspector to clear active overrides and show that choice. This preserves the saved model for Undo/removal, rather than deleting mesh data. The common frame is16 logical CSSpx×size with caller DPR/typeScale applied once; hit reach, reserves and label offsets follow it.

The existing aggregate before.edits/audit/RPC Undo has finite live+predecessor retention; no field inversion, later-edit preservation or outer-abort guarantee is added.
