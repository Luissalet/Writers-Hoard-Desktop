Method: read all 3,705 string keys of `D2-platform.txt` (data only), clustered them into capabilities, then opened Writer code to confirm each OFFLINE capability (R = repo "Writers hoard desktop"). Behaviour beyond what a label says is marked "(inferred)". Paths are relative to R. Prior matrix `tasks/worldcraft1041-feature-inventory.md` was read for overlap but not trusted as proof; every PRESENT/PARTIAL below was confirmed in code.
