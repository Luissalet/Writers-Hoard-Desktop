# Resolver referencias de documentos por lote

`client.refs.resolveMany?.(references)` resuelve metadatos en el proyecto y la era efectivos. Cada par `{kind, documentId}` se lee una vez y conserva su posición, incluso si se repite. Un documento propio de la era aporta sus metadatos, uno heredado conserva la procedencia Base, y uno oculto o ausente devuelve `available:false`. El lote vacío devuelve una lista vacía. Para obtener una ruta de apertura se usa `refs.resolve(reference, {includePath:true})`. MCP ofrece la lectura `wh_local_tool_reference_resolve_many` con el namespace Source y el ámbito del puente. [Guía del SDK](../../docs/local-tool-sdk.md#resolve-a-batch-of-document-references)
