## Top offline gaps worth implementing (ranked)

Ranking = user value for a writer/worldbuilder x fit with existing modules x cost.

### 1. To-do list document (rows 31) — size M
Value: a writer's task list linked to world documents; Writer has no task capability at all.
Sketch: ship as a built-in Local Tool using the existing SDK (`src/engines/local/sdk.ts` `defineLocalTool`, `codec` with a `list` field keyed by `id`, `embed:'interactive'`, preview spec for open count) so it automatically gets document-block embedding (`components/editor/toolBlocks`), era isolation, JSON/ZIP portability and `wh_local_tool_*` MCP access. State: `{items:[{id,text,status:'todo'|'in_progress'|'done'|'dropped',urgency:0-3,due?:ISO date,refs:[{kind,id}]}]}`; @-link via `LocalToolReferences` + `ReferencePicker.tsx`; filters (all / with due date); drop "assignee" (single user) or map to Codex character cards. Add a dedicated `wh_todo_*` thin wrapper only if the generic `wh_local_tool_state_apply` proves clumsy.
Risks: pick a namespace that cannot clash with user-installed tools; `installed/` modules are build-time globs, so the built-in must be registered like `registerInstalledLocalTools` does (or as a normal engine). No change to existing engines.

### 2. Soundscape mixer (row 37) — size M
Value: ambience layers for scenes; Writer has only single-track `ProjectSoundtrack` and per-chapter reader cues.
Sketch: new Local Tool (or `media` engine sibling) `soundscape` document: `{scenes:[{id,name,strips:[{id,kind:'loop'|'oneshot',assetId,gain,intensity}],master}], liveSceneId}`. Playback with WebAudio (`AudioContext`, one `GainNode` per strip + master) fed from `db.localMediaAssets` blobs (reuse `engines/media/types.ts` limits and `mediaKind`); loops via `AudioBufferSourceNode.loop`, one-shots fire on click; "Listen" starts only on user gesture (same policy as `ProjectSoundtrack.tsx`). Embed preview "N layers on". MCP: `wh_local_tool_*` or `wh_soundscape_get/set_scene`. Optionally bundle a small CC0 starter pack (licence check).
Risks: autoplay policy, memory for decoded buffers (cap 500 MB/project already), must release the context on unmount like `radar/audio.ts` does; do not alter Reader ambience.

### 3. Name generator tool (row 34) — size M
Value: quick names for inns/shops/people/villages/houses with a card created in the Codex.
Sketch: extend `src/engines/worldgen/core/naming.ts` (deterministic `Culture` phonology) with person/house name composers and 5 more cultures (slavic, east-asian, seafaring, fey/dwarven, far-future), plus small curated tables for kind (inn: adjective+noun, owner, charm, secret, trouble, motto). New UI as a Local Tool or a Codex dialog ("Name..."): choose kind + style + optional free brief; optional local model path via the existing AI runtime (`src/services/aiRuntime`) strictly optional and offline-first; "Make a card" calls the existing `createCodexEntry` / `wh_create_codex_entry` with the type mapping used by `suggestedEntityType`. MCP: `wh_generate_names` (read-only, seeded) + reuse `wh_create_codex_entry`.
Risks: keep generation deterministic per seed so worldgen place names do not change (existing maps depend on `(seed, kind, index)`); add new cultures as new ids, never reorder existing arrays.

### 4. Built-in rules compendium (rows 1-5, 64) — size L
