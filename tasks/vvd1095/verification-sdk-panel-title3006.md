# Author headings in Source document panels

## Author contract

Add top-level `panelTitle: false` to a `defineLocalTool` definition whose Source document component provides its own heading. Use the live `context?.document?.title` rather than copying the saved name into tool state. Omitting `panelTitle` or using `true` keeps the existing host heading. The validator rejects non-boolean values with `source_tool_document_invalid`; this option is not inside `document`.

In a live Source editor with host chrome, the host omits only its duplicate heading. The same document ID, stored title and data reach the component. Ordinary rename updates the title without replacing the document. Presence, Share local session, focus and Fullscreen retain their existing availability. Fullscreen still has a named dialog and Save and return. The flag does not apply to other document-host views.

A saved read-only fallback that replaces the component keeps the document heading. If the runtime boundary catches a render failure after the host heading was hidden, the existing notice identifies that document and offers Retry engine. Once Retry succeeds, the component's heading is shown again without a duplicate host heading. The option is presentation-only: it adds no stored document field, changes no rename version check, and introduces no MCP command or new permission.
