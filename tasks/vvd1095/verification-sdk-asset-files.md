## Contract and normal use

`client.assets.import(file,'font'|'data')` returns immutable project file metadata/ref without Blob. `choices(kind)` lists ref/title; selections use the existing document → installation → package cascade, aliases and exact compiled-release rules. File refs use a separate `{kind:'file',id}` domain. Project bytes are shared across eras; overrides remain era differences. Installation offers CAS+Revert without Undo; document/Owned choices retain native apply/Undo/Redo receipts, without deleting inventory. Import then choose are explicit UI operations; failed/stale choice preserves the draft/imported option for explicit recovery. Strict readonly/query imports remain denied; editable Owned imports use a separately revalidated host-port capability, without writable general world/media facilities.

The same three MCP tools gain choiceKind, includeContent and file/importOnly fields documented in [AI-BRIDGE](../../docs/AI-BRIDGE.md#recursos-de-herramientas-locales-fuente-d542365). Import+selection is atomic with CAS and receipts available only after the outer commit; a deliberate outer abort preserves both stores. ImportOnly does not select or return a state receipt. Block importOnly then block_apply is two explicit operations. No paths/URLs or unbounded transport claim. Audio still accepts only media/source refs.

`useLocalToolFontFace` loads an admitted asset with caller-owned FontFace cleanup, late-binding/StrictMode protection and honest loading/error state. Public imports remain Node-pure; no browser/font effect occurs on import. AssetPad's TTF demonstrates only A/space, not a general author font. The data default is JSON labels; opaque data is not executed. Admission uses50MiB/file and500MiB/project; Dictionary's512KiB limit is unchanged. There is no new inventory editor/delete/GC feature. [Usable SDK API](../../docs/local-tool-sdk.md#project-fontdata-files-and-font-loading).

JSON/project/full ZIP preserve actual bytes and validate size/MIME/SHA before writes, including old missing inventories. Duplicate/clone remap file/image/media separately even with equal literal IDs. Captured Reader/wiki/Published use admitted frozen bytes with DB closed, without live fallback or authored controls. includeImages controls images independently; includeMedia:false excludes font/data/other media but retains admitted gallery images. Only final admitted font markers emit generated CSS and conditional `font-src data:`; discarded raw previews and absent fonts do not alter legacy CSP/HTML. No author CSS is enabled. Existing wiki SVG framing and manuscript SVG policy remain unchanged.
