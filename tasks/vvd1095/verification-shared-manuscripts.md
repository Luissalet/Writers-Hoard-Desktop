Codex, maps, timelines and other world documents retain their existing world identities. There is no cloned world or new database table.

The Manuscripts library creates, edits, opens, archives and restores books. Archiving is reversible organisation and preserves editable chapters. The book editor, numbering, import destinations, Reader, positions, publishing profiles and captured editions use the selected book. Main cover/playback retain their canonical Project/era fields; other books own their cover/playback and era covers. Two panes can select different books, and changing scope flushes pending text without remounting the editor. A valid chapter link takes precedence over a contradictory book/library query.

Raw world-writing lists keep their previous world-wide default. Reader and publishing profiles default to the original manuscript; an explicit world compilation can combine books. Restoring a captured world edition requires an explicit destination. The new registered MCP tools are `wh_writing_manuscripts` and `wh_writing_manuscript_set`; the latter uses the observed catalogue revision and native audit Undo. Ordinary text saves cannot change ownership. Undo changes one entry against its own post-state and preserves unrelated world changes; create and owner validation share a transaction.

Project JSON remaps the catalogue, owners, era covers, publishing profiles and editable historical links within its existing exported data; it does not add Reader positions or reference pins to that format. Duplicate also remaps the manuscript-scoped reference pins and Reader positions. Both ZIP formats preserve the catalogue and ownership using archive IDs; Project ZIP retains its existing Reader-position reset on replacement, while Full ZIP carries settings. Same-ID restoration resolves the previous structural owner from live Base, archives and all era histories before clearing data. Missing legacy owners inherit that identity; an explicit incompatible owner or a resulting catalogue without the inherited book aborts the whole transaction. Captured publication sources retain canonical membership with the database closed. Existing frozen HTML/hashes are unchanged. Imported malformed source atoms remain unavailable during read-only capture while valid neighbouring image atoms survive; write validation remains strict.
