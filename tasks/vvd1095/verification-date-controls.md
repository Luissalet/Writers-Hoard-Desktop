# World-calendar date controls — task1095 / research1484

Use the calendar button beside an event or chapter's world date. Previous/Next browses the calendar without changing the authored value. Enter exact date stages separate absolute-year, month and optional-day fields; Apply publishes the draft and Cancel returns to the grid. Empty month/day preserves a year-only date; empty day preserves month precision. Existing approximate dates retain their approximation when applying the separate fields. Free text, the grid, weekday/moon/holiday reading and whole-month selection remain available.

Clear sends the existing empty-value contract to the consumer. An event still needs a start before Save; its optional end can be removed. A chapter can clear its start and end through its normal debounce. The field does not write to storage itself. Today appears only with a complete usable Earth correlation and converts the computer's local civil day through the existing calendar lens. A result before the calendar's permitted beginning leaves the value unchanged with an explanation. No correlation invents a world Today.

Month navigation skips absent leap months and keeps nonempty intercalary months. A calendar whose only configured month exists in leap years can have empty years: it retains the no-days message, a valid year-only example and bounded year-by-year navigation. Whole month cannot publish a nonexistent month. No calendar schema or validator was restricted to hide this case.
