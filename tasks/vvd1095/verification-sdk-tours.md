## Use and API

Compile the ordinary `examples.guided-counter` source, enable Guided counter / Contador guiado in Engine Manager and create/open a Counter document. Help starts or resumes the declared tutorial. Its intro has Next; the second step has no Next/Finish and completes only after Increment saves the real count. Reopening retains the count without auto-starting a tour. The existing legacy editor supports the same port. No example is enabled automatically and Help does not flush or save a document draft.

`defineLocalTool({tours:[...]})` captures an optional finite-JSON descriptor. Each tour has `id`, positive integer `revision`, `title` and ordered steps with `id`, `target`, `title`, `body`, optional `advanceOn`. Copy is `{en,es}` or `{key}` in the tool's own locale catalogs. Targets are `data-tour` values within the instance root. `context.tutorial` offers `show(id,{resume?})`, `signal(name)`, detached `getSnapshot()` and `subscribe(changed)`/unsubscribe. It is optional: missing/headless hosts do not fabricate shown UI.

The three modes are manual (including omitted advanceOn), event `{type:'event',name}` after a normal confirmed author action, and `{type:'element-appears',target}` visible in the same root. Result/appearance modes cannot be bypassed with Next/Finish, controller calls or ArrowRight. Back, Skip and Escape remain available. The host binds the effective selected release, client, project, era, document and instance through an irreversible committed lease. Hidden/retargeted/pinned/unmounted/StrictMode-old ports cannot revive. Changing interface language changes copy without restarting the step. Fullscreen revokes the underlying tour; Owned/world blocks, readonly views, exports and fullscreen have no tutorial port in this extension.

Progress is app-wide settings data, separate from authored documents and world backups. Its canonical key uses namespace/tour ID/revision and the ordered ID/target/condition tuples. Copy, locale and package hash are excluded; recompiling or changing text keeps learning, while a structural change starts separately even if revision is unchanged. Omitted/manual normalize only for the key: describe preserves the exact declaration. Existing records and nine global tutorials remain intact.

`wh_local_tool_describe` includes detached `tours` only when declared. `includeTutorialState:true` requires projectId, admits eraId and reports only currently mounted matching Source/legacy editor snapshots of the selected release. A different exact compiled candidate cannot borrow the active release's state. No new tool, permission, UI start RPC or headless show is added. Fake host tutorial/commands record intent; show returns false/unavailable without DOM. [Usable public API](../../docs/local-tool-sdk.md#optional-tutorials-for-source-and-legacy-editors); [MCP read contract](../../docs/AI-BRIDGE.md#recorridos-opcionales-de-herramientas-fuente).
