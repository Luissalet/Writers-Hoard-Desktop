# B-campaign cross-reference: VVD "campaign" (TTRPG campaign manager) vs Writer

Scope: all 2962 lines of `B-campaign.txt` read. Writer repo: `Writers hoard desktop` (read-only). Paths are relative to the Writer repo root.
Method: strings clustered into capabilities; ONLINE = needs a server by nature (multiplayer, invites, hosting, publishing, third-party fetch). For OFFLINE rows the Writer code was opened (not name-matched). "(inferred)" = behaviour inferred from labels only. The existing `tasks/worldcraft1041-feature-inventory.md` (148 rows, IDs W/C/G/B/T/L/Q/D/R/X/M/A/P/S) has **no campaign/session-prep/encounter rows**; it was used only for overlap IDs and NOT trusted as proof.

Key Writer facts found that drive the classification:
- `src/engines/fiction` + `story/writer_story` (incorporated Scheherazade, Python stdio worker, SQLite): worlds (premise, tone, ruleset freeform/d20/pbta_2d6, content_lines/veils, rules_text, calendar_json), entities with GM `secrets`, facts, relations, timeline events, threads, clocks, random tables, sessions (id,title,started_at,ended_at), turns (role narration/action/dialogue/ooc/roll/system, delta, undo), dice_log, continuity check (`world_check`), narration/voice/illustration (need hub/model), exports. 19 `fiction` MCP tools + `wh_story_modules`, `wh_story_module_set` (`src/services/aiBridge/manifestFiction.ts`, `docs/FICTION.md`).
- `src/engines/character-sheets`: CoC 7e, 5e (SRD 5.1 class preview, spell slots, resources), 5e stat block (CR to XP/PB), Daggerheart PC and adversary, paper/ink, dice history; tools `wh_sheet_*`.
- `src/engines/local` (local-tool SDK) with only an example `InitiativeCounter` (round + name/initiative list + notes).
- `src/engines/writings` (manuscript, Read/Play reveal, tool dock, published editions), `outline`, `timeline` (+world calendar `wh_world_calendar_*`, `wh_world_date`), `annotations`, `notes` (flat), `maps`, `worldgen` (journeys), wiki profiles (`wh_wiki_profile_*`), `services/storyState` (beliefs with `revealedAtMomentId`).
