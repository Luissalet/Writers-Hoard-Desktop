## Delivered contract

Each Timeline can hold an optional preset catalogue. A preset has its local ID, name, style and optional archive state. Events retain their manual style and may also carry a live link identified by project, effective era, ownerTimelineId and preset ID, with a captured fallback. IDs, rather than names, resolve the owner: moving an event into a Timeline with a same-named preset never adopts that preset. Archived presets remain usable by existing links, are excluded from the normal picker and can be restored. This is Writer's reversible archive contract; deletion of a used preset in the reference was not observed.

Live resolution reads the current valid preset, otherwise the valid captured fallback, otherwise safe manual paint. Reading and preset edits do not migrate events or write inherited values into them. Event colour wins by default; Use preset colour opts into the owner's colour. Manual controls retain the saved layer while linked. Independent copy materializes the effective shape/fill/parameters/image/colour and removes the link; explicit edits made in the same form, including colour, override the copied values. Unchanged baseline fields travelling in a full form patch are not explicit overrides. Return to saved manual style removes only the link.

Shape remains separate from paint: Plain/Ribbon/Bunting/Scallop coexist with Solid/Stripes/Dots/Checks/Crosshatch/Grid/Image. Optional repeat size and opacity apply to paint, leaving labels, base colour and shape readable. Missing parameters preserve the old geometry of Stripes/Dots/Checks; saving only a title does not materialize new defaults. Image paint is separate from an event's existing illustration. File and the same-project Gallery copy raster bytes into the style; the banner does not depend on the gallery row continuing to exist. File reads are bound to project/era/Timeline/draft and are cancelled or ignored after retarget. No external API or payment is required.

Both existing move gestures, the Timeline selector and swimlane drag, preserve the original owner and manual layer and capture the effective fallback atomically with the move. In an era, removal from the old aggregate and insertion into the destination are one composed mutation. The form keeps raw storage baselines captured when opened, rather than treating a projected world-calendar label as stored data.

Catalogue writes compare the parent version. Live/copy/manual and moves use the same event seam from normal UI and MCP. Scoped Undo compares the affected fields/entry/order, preserves later unrelated prose and neighbours and rejects real conflicts. The receipt and notification become visible only after an enclosing transaction commits; abort retains retry/Undo correctness. Optional empty catalogue and absent catalogue remain distinguishable. Existing legacy writes do not acquire new token obligations merely because paint fields were added.

## Use in the normal interface

1. Open Timeline, choose the owning Timeline and Banners. Create a named preset, choose shape and fill, and optionally set size/opacity or choose a raster through File/Gallery. Save.
2. Open an event through its existing editor. Choose the live preset and optionally Use preset colour; Save. Editing that preset later updates the linked band's paint without reapplying it.
3. Choose Independent copy to retain the current effective appearance independently, or Return to saved manual style to restore the untouched manual layer. Save and use Undo banner change if needed.
4. Move through the existing Timeline selector or drag. The link still names the original owner. Archive/Restore operate in that owner's catalogue; archiving a used preset does not blank the event.
