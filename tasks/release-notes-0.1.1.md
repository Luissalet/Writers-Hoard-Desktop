# Writers Hoard 0.1.1 — voz, fuentes y procesos de escritura

Versión preliminar para Windows y Linux, con nuevas herramientas para narrativa, periodismo y ensayo.

## Novedades

- **Voz y contexto del proyecto:** guarda estilo, público, criterios y contexto. Puedes proponer una voz desde textos propios y comparar una edición con y sin el perfil.
- **Afirmaciones y fuentes:** relaciona datos, declaraciones e interpretaciones con citas o recortes, fragmentos literales y ubicación. Registra lo pendiente, revisado o cuestionado.
- **Procesos de escritura:** recorridos editables para reportaje, ensayo y narrativa, con material seleccionado, historial, recuperación de borradores y creación de escritos sin duplicarlos.
- **Asistencia conectada:** perfil editorial compartido con copiloto, análisis y revisión; consulta de contexto y evidencias desde MCP.
- Protección ante ediciones simultáneas y conservación de fuentes, referencias y versiones en copias compatibles.

Las herramientas están en el **Centro creativo**: **Desarrollar → IA contextual** y **Producir → Citas / Flujos**.

## Descargas

- **Windows x64:** `Writers-Hoard-Setup-0.1.1.exe`. Instalador sin firma digital, como la versión preliminar anterior.
- **Linux x64:** `Writers-Hoard-0.1.1.AppImage`. Concede permiso de ejecución para abrirlo. Las herramientas multimedia completas requieren glibc 2.38 o posterior; gallery-dl no funciona con glibc 2.36.
- **SHA256SUMS.txt:** sumas de comprobación. Los archivos `.yml` y `.blockmap` son para el actualizador.

## Comprobaciones y alcance

325 comprobaciones críticas aprobadas, recorridos de interfaz y compilación de producción. La IA requiere una conexión configurada; los modelos no se incluyen. La revisión de afirmaciones refleja el criterio del autor y no certifica su veracidad. Esta entrega utiliza fuentes incorporadas al proyecto; no añade búsqueda web autónoma, OCR ni transcripción.

Los archivos «Source code» generados por GitHub contienen la documentación pública del repositorio de releases. El código fuente de desarrollo permanece privado.
