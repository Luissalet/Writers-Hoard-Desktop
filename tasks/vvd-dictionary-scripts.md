Fonts are limited to 512 KiB to reduce pressure on existing localStorage recovery journals. Global storage quota failures remain tracked by the existing pending-write recovery mechanism; live drafts stay available for saving/retry. No guarantee is made that global storage pressure cannot exhaust recovery space. Font bytes render via validated ArrayBuffers, never remote URLs. Invalid legacy project font metadata is dropped during project cloning; native forms themselves remain intact.

References: Unicode character charts for [Tifinagh](https://www.unicode.org/charts/PDF/U2D30.pdf), [Ogham](https://www.unicode.org/charts/PDF/U1680.pdf), [Runic](https://www.unicode.org/charts/PDF/U16A0.pdf), [Glagolitic](https://www.unicode.org/charts/PDF/U2C00.pdf). These are editable visual substitutions for worldbuilding, not linguistic transliteration. No font is extracted from those charts or bundled from outside sources.
