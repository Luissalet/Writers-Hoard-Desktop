## Procedencia y cautelas de método

- Las páginas de ayuda de julio/agosto no son especificación exhaustiva actual: el changelog de septiembre/octubre añade tipos de propiedades y edición avanzada, entre otros. Se han separado sus niveles de prueba.
- El parser web no abre algunas fichas `/t/`; HTTP directo sí entrega su texto y las secciones de contenido serializado de la página. Se leyeron esas descripciones sin ejecutar JavaScript ni descargar módulos del producto. El contenido no convierte la descripción en prueba live.
- Un intento inicial de lectura de Dialogue devolvió404 y el bucle conservó temporalmente el texto anterior de VoiceMemo: **ese texto no se atribuye a Dialogue**. La descripción Graph/Walk procede exclusivamente del resultado cacheado de búsqueda. Se corrigió el manejo de HTTP antes de continuar.
- No se reutilizó código/artwork/fonts/modelos de VVD. Sus enlaces de «View source» no se siguieron.
- Esta reconciliación no ejecuta producto: distingue EP-E de frentes ejecutados antes por este agente y EP-R de ejecuciones ajenas leídas en informes/logs. Las limitaciones actuales se contrastaron con código; el conjunto WIP no certifica un commit ni una integración.
