# Production handoffs

Writer declares production handoffs for a brief, a scene brief, a research dossier and an editable report. The Hub can plan from these declarations. Reread the manuscript or reopen the report to check the result against its source material. The publishing and story groups expose their native module switches through the Hub.

The Hub's Start control runs the repository's desktop launcher after the source checkout has been set up. The launcher builds the desktop bridge and MCP adapter from the same source. Use Settings → AI bridge to enable the listener and choose whether it accepts writes.
